# Portfolio — François

Bienvenue sur le dépôt GitHub de mon portfolio personnel !

Ce site présente mon parcours, mes compétences et mes projets en développement web.

Actuellement en formation **Développeur Web et Web Mobile (DWWM)**, je suis en reconversion professionnelle après plus de **20 ans d'expérience dans le secteur automobile**.

Passionné d'informatique et de nouvelles technologies, je souhaite aujourd'hui mettre mes compétences en pratique et poursuivre mon apprentissage au sein d'une équipe de développement.

Ce portfolio a été conçu pour :

- Me présenter et partager mon parcours professionnel.
- Mettre en valeur mes compétences techniques.
- Présenter mes projets réalisés pendant ma formation et mes projets personnels.

## 🚀 Installation et utilisation

Pour consulter le portfolio en local :

1. Cloner le dépôt GitHub :

```bash
git clone https://github.com/Francoiskos/Portfolio.git
```

2. Ouvrir le dossier du projet dans Visual Studio Code.
3. Ouvrir le fichier `index.html` dans un navigateur.

Le portfolio est développé principalement avec HTML, CSS et JavaScript.
